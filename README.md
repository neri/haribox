# HariboteBox

## About

[はりぼてOS](http://hrb.osask.jp/) のアプリをブラウザー上で実行できるデスクトップ環境エミュレーターです。

HTML + TypeScript で実装されたデスクトップ環境と、
WebWorker 上の Rust + WASM の x86 エミュレーターで構成されています。

内蔵ファイルシステムは理論上ブラウザーのメモリが許す限り保存できますが、
LocalStorageを圧迫しないために約1.5MBの制限を設けています。

現在ベータ運用中です。

## 使い方

* ファイル一覧から HRB ファイルを選択すると GUI アプリが起動します。
* 一部のアプリはターミナルでコマンド入力が必要なものがあります。
* ターミナルでは HELP コマンドで使用可能なコマンドを確認できます。
* ドラッグアンドドロップで外部の HRB ファイルを localStorage に取り込めます。

## ビルド

* `mise` がある場合、 `mise run build` でビルドできます。ない場合は `make` を実行してください。

### 必要なもの

* pnpm, Node.js, TypeScipt
* Rust nightly, wasm-bindgen-cli

## 制限・既知の問題

### CPU エミュレーターについて

CPUエミュレーターはまだ完成度が低いため、内蔵アプリの動作は概ね検証済みですが、外部のアプリはうまく動作しない場合があります。

### 日本語エンコーディング問題

はりぼてOSは日本語を主にShift JISで扱いますが、現代の環境ではUnicodeが一般的です。
ウィンドウ内の描画は専用フォントで正しく描画できますが、ターミナルやウィンドウタイトルで日本語を使うと文字化けが発生することがあります。

### スマホやタブレットでの動作

iPad に物理キーボードを繋いだ場合、ほとんどの操作は問題なくできます。
スマホは画面が狭いのでレイアウト崩れが起きやすく、アプリ上のキー操作もうまくできない可能性が高いです。
