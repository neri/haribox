## 1. 目的

Webブラウザ上で動作する SPA として、「はりぼてOS」というOSのアプリケーションを実行する環境をエミュレートする。本プロジェクトはこのエミュレーター環境の **ウィンドウシステムとシェルUI** の実装に主眼を置く。

### 1.1 アプリ全体の役割

- Webブラウザ内で「はりぼてOS」のOS環境をシミュレート
- Rust/Wasm で実装されたOS上のアプリケーションを実行
- ウィンドウベースのマルチタスク環境を提供

### 1.2 本プロジェクトの実装範囲

Webブラウザ内に以下のUIを実装する:

- **デスクトップ環境**: 画面全体をデスクトップとして表示
- **ウィンドウシステム**: 複数ウィンドウの生成、移動、前面化、個別クローズ
- **シェル（ターミナル）**: コマンド入力・実行・結果表示
- **ファイルシステム UI**: メモリ上の簡易ファイルシステムと localStorage 永続化
- **ファイル管理**: デスクトップへのドラッグ&ドロップによるファイル取り込み
- **タスク実行**: ターミナルコマンド経由で Worker 上の Rust(Wasm) タスクを実行

## 2. 適用範囲

### 3.1 本プロジェクトのスタック

- 言語: TypeScript
- 実行環境: Webブラウザ (SPA)
- パッケージマネージャ: pnpm

## 4. 用語定義

### 4.1 システム構成

- **はりぼてOS**: メインのオペレーティングシステム（別プロジェクト）
- **エミュレーター**: Webブラウザ上の仮想環境。はりぼてOS のアプリを実行する
- **HDE (Haribote Desktop Environment)**: 本プロジェクト。エミュレーター上のウィンドウシステムとシェル UI

### 4.2 UI 要素

- デスクトップ: 画面全体の作業領域。デフォルト色は青緑。
- タスクバー: 画面下部の固定操作パネル。
- ウィンドウ: デスクトップ内に配置される可動要素。
- ウィンドウID: 各ウィンドウのユニークな識別子（UUIDv4 文字列形式）。複数インスタンス可能なウィンドウタイプでも個別に異なる ID を持つ。
- アプリID: ウィンドウタイプそのものの識別子（UUIDv4 文字列形式）。同じタイプのウィンドウは同じアプリID を共有。1 個限定ウィンドウの判定などに使用。
- Zオーダー: ウィンドウの前後関係。
- アクティブウィンドウ: キーボード入力フォーカスを持つウィンドウ。ウィンドウ内のサブアプリケーション（ターミナル、ファイルマネージャなど）は、アクティブなウィンドウのみがキーボード操作を受け付ける。ウィンドウをクリックするとそのウィンドウがアクティブ化される。
- デフォルト端末ウィンドウ: 宛先端末が曖昧なメッセージ表示に使用される端末。最初に開いた端末ウィンドウがデフォルトとなり、その後複数存在する場合も最初にデフォルトになったウィンドウが優先される。デフォルト端末を閉じた場合は次の端末候補を探す。端末が1個のみの場合はそのウィンドウがデフォルト。端末が存在しない場合はダミーウィンドウとして扱う（エラーにはならないがメッセージは表示されない）。
