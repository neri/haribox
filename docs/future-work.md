## 2. 将来の課題

### 2.1 スマホ対応

- **ターミナル表示の問題**
  - スマホではターミナルが見切れる
  - 対応方針: レスポンシブレイアウトの実装、ウィンドウサイズの最小化オプション、スクロール機能の改善

- **キー入力の問題**
  - アプリのキー入力に課題（物理キーボードなし環境での操作性）
  - 対応方針: オンスクリーンキーボードの実装、タッチジェスチャーのサポート、コマンド入力補助機能の追加

### 2.2 Rust/Wasm機能拡張
- より複雑なアプリケーション実装（画像処理、音声処理、ゲーム等）
- インタラクティブな入力処理（キーボード・マウスイベント）
- Canvas への高頻度描画（アニメーション・ゲームループ）
- Worker 間通信や複数タスクの同時実行
- 外部 Rust クレート（image, audio 等）の統合
- 現在のインターフェース仕様は [Rust/Wasmインターフェース](./rust-wasm-interface.md) を正本とする

### 2.3 キーボード入力拡張

**現在実装済み:**
- `keydown` の印字可能ASCII文字、Backspace、Enter、Esc、PageUp/PageDown、Home/End、矢印、Insert、Delete をイベントコードとしてRustへ渡す
- 左右を区別した修飾キー情報をイベントコード上位ビットへエンコードする
- `keyup` はMainからWorkerへ転送するが、イベントキューには追加しない

**将来的な対応:**
- keyup を含むキー状態変化をRustアプリケーションへ公開する方式の検討
- キーボードレイアウト・IME・非ASCII入力への対応
- ウィンドウ単位のイベントキューが必要になった場合のキュー分離

### 2.4 ウィンドウ機能拡張

- **最小化機能**
  - 既にアクティブなウィンドウのボタン再クリック時にウィンドウを最小化（非表示）
  - 現在は将来機能として記載のみ
